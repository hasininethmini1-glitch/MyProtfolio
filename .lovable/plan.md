# Hasini Nethmini Portfolio

## Overview
Build a responsive, single-page developer portfolio that accurately presents Hasini as an HNDIT undergraduate, IT Intern, and Trainee Software Developer. The visual direction will be a sophisticated charcoal developer workspace with a restrained teal accent, crisp typography, subtle grid/code-inspired details, and lightweight motion.

## What will be built
- Sticky blurred navigation with active-section tracking, mobile menu, and CV download action.
- Hero with professional positioning, social links, calls to action, and an abstract developer-oriented visual.
- Profile highlights, About, categorized Skills, Banking Internship, Featured Projects, Education, Courses & Certifications, Professional Journey, Languages, and What I Bring.
- Four interactive project cards, with the first emphasized and accessible project detail dialogs. Only the three supplied repositories receive GitHub actions.
- Accessible contact form with client-side validation and a clear confirmation state that opens the visitor’s email application.
- Responsive footer navigation and social links.

## Content and maintainability
- Centralize personal details, links, skills, projects, experience, education, courses, and the CV path in a typed data file.
- Build focused reusable section, card, dialog, and navigation components.
- Keep future fields ready for real demo URLs and certificate images without displaying placeholder actions now.
- Link both CV buttons to `/Hasini-Nethmini-CV.pdf`; the actual PDF can be added to the public assets when available.

## Quality
- Semantic page structure, one H1, keyboard-accessible interactions, visible focus states, reduced-motion support, and strong contrast.
- Responsive checks on desktop and mobile, including menu, dialogs, form states, wrapping, and horizontal overflow.
- Route-specific title, description, Open Graph, Twitter, and canonical metadata.
